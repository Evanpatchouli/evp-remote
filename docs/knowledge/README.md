# Reusable findings

A successful signaling exchange establishes that the peers can coordinate. It does not identify the path taken by media. Inspect the selected ICE candidate pair on the active transport. A relay candidate at either end means the measured path is relayed. A non-relay pair on two independently confirmed networks establishes cross-network direct connectivity in that test topology.

Receiving a video track, decoding a frame, displaying the first frame, and accepting input are separate milestones. Record them separately when investigating a black screen or slow response. See the [reference analysis](../architecture/gameviewer-analysis.md).
