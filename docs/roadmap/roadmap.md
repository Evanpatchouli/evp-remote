# Roadmap

1. Establish the evidence baseline, contributor workflow, and Windows session contract.
2. Deliver an attended host and viewer, pairing, screen and system sound, keyboard and mouse, and automatic ICE relay fallback. Qualify on independent Windows networks.
3. Measure startup, actual frame delivery, audio sync, input latency, and recovery across direct and relay routes.
4. Add [My Devices](../specs/my-devices.md): persistent local trust, accountless pairing, presence, and one-click control alongside Remote Assistance.
5. Expand native capture and codec tuning, multi-monitor support, virtual devices, and platform coverage using the [parity plan](../exec-plans/gameviewer-reconstruction.md).

Mark cross-network field acceptance complete only after retaining results from two authorized Windows machines and the public test infrastructure.

On 2026-11-19 the operator accepted the [first Windows build](../../README.md) as a proof of feasibility after a successful two-PC session. The [validation record](../evidence/windows-v1-validation.md) distinguishes this milestone from route-specific and performance qualification.
